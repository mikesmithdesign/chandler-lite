# Chandler Lite - free single-page template for cafes & coffee shops

A single-file HTML template with a live open/closed badge, a daypart-aware
"on the counter" ticker and warm, colour-committed typography. No build
step, no frameworks, open `index.html` and edit.

**Live demo:** https://chandler-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html`, cafe name, hero copy, the counter
   tiles, the story paragraph, address and contact details.
2. Replace the photos in `img/` with your own (keep the filenames, or
   update the `src` paths).
3. Set your opening hours in the `HOURS` table near the top of `site.js`
   (day 0 = Sunday; `[7,16]` = 7am-4pm).
4. Upload anywhere, it's static files. Vercel, Netlify and GitHub Pages
   host it free.
